What is `<tool_call>`? It's a special token/literal string used in chat model / tool-calling serialization formats. In many chat templates (e.g., some models like Hermes, or in general function-calling formats), the model emits text like:

<tool_call>
{"name": "get_weather", "arguments": {"location": "Prague"}}
</tool_call>

It's a special control token marking the beginning of a tool/function call block in the model's output stream. It's part of the ChatML-like / Hermes-style function calling format. It's used by inference frameworks (vLLM, llama.cpp, Ollama, text-generation-webui) to parse the model's raw text output into structured tool calls, and it's also registered as a stop token / special token so the generation stops or is intercepted at that boundary.
